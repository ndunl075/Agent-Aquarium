# Aquarium UI

The tank is the main view. Each observed parent session receives its own illustrated fish; real subagents receive smaller fish. Select a fish or its keyboard-accessible session card to see the latest observed activity. Context is **Unknown** unless the provider supplies a value. A stale fish says **Activity unknown**, not finished.

## Getting started

- **Connect Claude Code** opens the exact configuration preview. **Approve & install hooks** is the explicit installation action. Existing settings are backed up and merged by the companion installer. Start or resume a session afterward.
- **Remove Aquarium hooks** reverses only the Aquarium installation. **Check connection** shows safe local diagnostics.
- **Watch the demo** asks the main process to supply five simulated agents. Each fish and card is labeled **DEMO**. The renderer does not manufacture live events.
- A standalone Vite browser preview is labeled **ARTWORK PREVIEW** and contains five static simulated states for visual review. Local integration actions are unavailable there.

## Reading the water

Working fish cruise. Reading and searching fish inspect their surroundings. Writing fish settle toward the coral. Shell activity produces quicker routes; tests use a gentle zigzag. Waiting fish hover and show **! NEEDS YOU**. Completed turns briefly celebrate and retain their fish. Errors show **× ERROR**; unknown activity is muted and marked **? UNKNOWN**. Status uses text and symbols as well as color.

Fish appearance derives from a stable identity hash: original procedural bodies, patterned scales, articulated tail and fins, and three silhouettes in five palettes. No downloaded art, remote fonts, runtime AI calls, or paid services are used.

## Privacy and preferences

The shield button enables **Capture privacy**, replacing project labels with fish colors and hiding the inspector and session strip. Screenshot export enables privacy first and waits for the masked view to paint before asking the desktop process to save locally. Capture privacy remains on after export; use the shield to leave it. Hook preview paths and diagnostic details are also hidden in capture mode.

Settings include reduced motion, battery saver, Always on Top, optional sound and notifications, local history, history retention, diagnostics, and an explicit confirmation for clearing stored session data. Mini Tank keeps the scene and status counters in a compact window.

## Accessibility and rendering

Every fish is also represented by a keyboard-accessible session button. Side sheets have dialog labels, trapped tab navigation, Escape dismissal, and restored focus. OS reduced motion is honored automatically. Unknown telemetry is never displayed as zero. On GPU initialization failure or context loss, a usable static session view replaces the animated scene.

One Pixi ticker drives all fish, fins, plants, and a fixed pool of 42 particles. Frame delta is capped after suspension. Hidden windows throttle to 3 FPS; battery saving and reduced motion cap at 30 FPS. Device-pixel ratio is capped at 2. React renders only on state or UI changes. Sequence gaps request a fresh domain snapshot.

The interface uses local Segoe UI/Arial and Georgia fallbacks. The React entry point is `apps/desktop/src/renderer/main.tsx`.
